# Deploying this portfolio to Vercel

This is a static HTML and CSS site. No build command or framework preset is needed.

## Deploy

1. Import this GitHub repository (`Stringpappy/Myportfoli`) into Vercel.
2. Leave the Framework Preset set to **Other**.
3. Leave the Build Command and Output Directory blank (or use `.` as the output directory if prompted).
4. Deploy. Vercel will serve `index.html` from the project root.

The site stylesheet and images are served from their existing relative paths.
